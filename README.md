## 📌 Projeto em destaque

### 🛍️ StoreLink — Trabalho de Conclusão de Curso

O **StoreLink** é uma aplicação web desenvolvida como projeto de TCC, com o objetivo de conectar consumidores e estabelecimentos comerciais por meio de uma plataforma digital.

**⚙️ Tecnologias utilizadas:**
- Django
- HTML
- CSS
- JavaScript
- Bootstrap

**✨ Funcionalidades do projeto:**
- Cadastro e autenticação de usuários
- Perfis de consumidores e lojas
- Busca de lojas, produtos e serviços
- Organização de estabelecimentos por categorias
- Interface responsiva e modo escuro

📍 **Status:** Em desenvolvimento
